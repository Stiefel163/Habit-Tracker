# Comeback: UX decisions

**The goal:** track whether I did it, and see progress in a fun way. It should be dead simple, accessible and quick.

## The one rule

**Each check grows today's tree.** 0 checks is a seed, all checks is a full tree with blossoms. Every habit you do hangs a fruit in its color, so the tree also shows *what* you did. The card next to it says it in words: "4 / 7 · Young tree · 3 more checks for a full tree".

## Why it looks like this

- **No times, no detail forms.** Every habit is one tap, done or not done. Training and Create open a short list (Gym / Swimming / your sports; Worked on content / Published a video), because those choices feed the goals.
- **Daily feedback, long-term meaning.** The tree answers "how's today going?". The Forest calendar answers "how did this month go?". Goals answer "am I getting there by December?".
- **Nothing is punished.** A missed day is just a small tree. There are no streaks to lose and no red states.
- **Fun without noise.** The tree and its fruits animate as they grow, the full tree sways gently, and there's one short message for a full tree or a reached goal. Each goal unlocks an animal: Grizzly, Beaver, Wolf, Parrot, Moose, Fox, Eagle, Owl, Squirrel and Hare.

## What we count, and why (research)

- **Measure only what tells you where you stand.** In a meta-analysis of 138 experiments, monitoring progress improved goal attainment (d ≈ 0.40), especially when progress was physically recorded (Harkin et al., 2016). So the two things with a real finish line get numbers:
  - **Bögen** (practice sheets), with passed / not passed. Passing means ≤ 10 error points in the class B exam, so "passed of your last 10" is a direct readiness signal.
  - **Study time**, as quick blocks. Blocks give minutes *and* sessions with one tap, and there's no timer to start.
- Everything else stays a single check, because a number wouldn't change what you do next.
- **Morning lock-in is an if-then plan.** "When I wake up → out of bed → breakfast → start something" is an implementation intention, which has a medium-to-large effect on goal attainment (d ≈ 0.65, Gollwitzer & Sheeran, 2006). It stays separate from sleep: good sleep makes getting up easier, but the lock-in is about what you do in the first hour.

## Screens

| Tab | Job |
| --- | --- |
| Today | Tree + 7 habit rows + this week's mini trees (tap a day to fill it in) |
| Forest | Trees planted, full trees, animals, and a month calendar of trees |
| Goals | Semester goals with progress bars and the animal each one unlocks |
| Settings | Habits on/off, your sports, goal numbers, appearance, backup |

## Removed on purpose

The pixel world, the cabin, "strong weeks", sleep clock times, training splits and durations, Spanish minutes, the week and month analytics, and the journal line. Each one was something you had to learn or fill in, and none of them helped you decide whether you'd done the thing.
