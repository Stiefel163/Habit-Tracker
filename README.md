# Habitat – Habit Tracker

Ein Habit Tracker im Stil von *Forest*: Je länger du deine Streaks hältst, desto lebendiger wird deine Welt.

**Zwei Welten zur Auswahl** (oben umschalten):

- **Kanadischer Wald**: Rocky Mountains, See und Fichten. Freischaltbar sind Eichhörnchen, Schneehase, Biber, Bartkauz, Rotfuchs, Eistaucher, Weißkopfseeadler, Weißwedelhirsch, Grauwolf, Wapiti (Elk), Schwarzbär, Elch (Moose), Grizzly und am Ende Nordlichter.
- **Unterwasser**: Seetang, Korallen und Lichtstrahlen. Freischaltbar sind Fischschwarm, Krabbe, Garnele, Kugelfisch, Tropenfisch, Oktopus, Qualle, Meeresschildkröte, Seehund, Delfin, Hai, Buckelwal, Blauwal und am Ende Meeresleuchten.

## So funktioniert's

- Jede Gewohnheit pflanzt einen Baum (bzw. Seetang). Er wächst mit der Streak dieser Gewohnheit.
- **Punkte = Summe aller aktuellen Streaks.** Bei bestimmten Punktständen ziehen neue Tiere ein.
- Reißt eine Streak, sinken die Punkte, und Tiere ziehen wieder weg. Der Baum wird zum vertrockneten Setzling.
- Heute abhaken mit dem großen Kreis; die letzten 6 Tage lassen sich über die kleinen Punkte nachtragen.
- Mit **Vorschau** kannst du dir anschauen, wie die Welt bei z. B. 150 Punkten aussieht.

## Starten

Einfach `index.html` im Browser öffnen. Keine Installation, kein Build.
Daten werden lokal im Browser gespeichert (`localStorage`). Unter „Daten sichern“ kannst du ein Backup kopieren und auf einem anderen Gerät einfügen.

Tipp fürs Handy: Über GitHub Pages hosten und dann „Zum Home-Bildschirm hinzufügen“.
